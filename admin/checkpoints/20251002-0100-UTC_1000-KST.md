## Summary

- 플러그인 초기 로딩 시 모든 섹션이 자동 선택되는 문제를 해결하고, Dry Run 시 선택한 섹션만 실행되도록 수정했다.
- Dry Run 프리뷰 프레임을 좌표(-2100, -1300) 위치에 2000×1200 크기, 회색(#f3f4f6) 배경으로 고정 생성하도록 런타임을 조정했다.
- 프리뷰 템플릿을 구성하는 `Preview:Banner`, `Preview:Canvas`, `Preview:SummaryPanel` 구조를 소스로 추가하고, Dry Run 결과 요약(선택 섹션/페이지/생성 노드/경고 등)을 노란 영역에 채워 넣도록 구현했다.
- 여전히 기존 섹션이 Slot 구조에 렌더링되어 분홍 영역 오버레이가 완성되지 않은 상태이며, 적용(Apply) 흐름과 연동된 프리뷰 클리닝 로직이 미구현이다.
